# packages

Shared TypeScript packages.

| Package | Purpose |
|---|---|
| `brand/` (`@nexusthrive/brand`) | Design tokens, base CSS, Tailwind v4 theme, fonts and logo |
| `ui/` (`@nexusthrive/ui`) | Design system components with Tailwind, documented in Storybook |
| `app/` (`@nexusthrive/app`) | Screen logic shared by web, mobile and desktop: state, routes, view models |
| `sdk/` (`@nexusthrive/sdk`) | Client generated from `contracts/`. Never edited by hand |
| `i18n/` (`@nexusthrive/i18n`) | User-facing strings by locale (`es`, `en`) with stable keys |
| `config/` (`@nexusthrive/config`) | Shared tsconfig and ESLint presets |
