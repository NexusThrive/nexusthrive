# @nexusthrive/sdk

TypeScript client generated from `contracts/` with `buf generate`. Never edit generated files; change the contract and regenerate (`task gen`).

## Initial generated contract

`src/gen/kernel/v1` contains the generated `kernel.v1` messages, service
descriptor, operation policies and public error codes. There is no handwritten
transport client yet. Prepare tools with `task tools:contracts` after installing
workspace dependencies, then run `task gen` from the repository root.
