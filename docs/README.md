## Tres capas de pensamiento

Todo lo que se escribe aquí cae en una de tres capas, y nunca se mezclan:

- **Visión:** lo que NexusThrive llegará a ser. Se escribe y se cuida; no se programa todavía.
- **Fundamento:** lo que debe existir para que la visión sea posible. Se diseña con cuidado.
- **Implementación:** lo que programamos y vendemos ahora.

> La visión atrae, el fundamento ordena y la implementación paga.
