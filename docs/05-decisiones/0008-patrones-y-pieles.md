# 0008 · Patrones con código, pieles con configuración

**Estado:** aceptada

## Decisión
Dentro de una distribución:
- Un **patrón** es una forma de operar con funciones propias (Membresía, Productos, Preparación, Servicio con agenda, Proyecto).
- Una **piel** es un rubro sobre un patrón: vocabulario, roles, campos y flujos en YAML.

## Consecuencias
- Un rubro nuevo casi siempre es solo configuración.
- El código crece únicamente cuando aparece un patrón realmente nuevo.
