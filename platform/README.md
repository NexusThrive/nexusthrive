# platform

The NexusThrive platform layer. It sits above every space and powers the NexusThrive console: staff and staff roles, plans and subscriptions, charges and billing policy, trial and benefit codes, skin releases and rollouts, capability requests, support tickets and audited support access.

It runs inside the kernel process as a privileged extension and owns the `platform` database schema.

Documentation (Spanish): `docs/02-arquitectura/plataforma/`.
