# integrations

Avisos y conexiones con otras apps mediante n8n: WhatsApp, correo, SMS, push, Telegram, Google, Shopify, marketplaces.

n8n escucha las señales del kernel y pide acciones por la API. Nunca guarda ni mueve valor por su cuenta.
